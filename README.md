# 公众号图文排版工具 · AI 复用包

把自己的文章、图片和排版偏好交给 AI，生成带复制按钮的独立网页。调好后保留规则，下一篇继续用。

**这是「模板 + Skill + 示例 + 教程」，不是在线 AI 编辑器。** 网页负责预览与复制，AI 负责替换内容、调整排版；网页没有 AI 服务费用，也不需要公众号密码或 API 密钥。你使用的 AI 服务可能有自己的费用和文件处理限制。

## 先体验

下载并解压整个项目，用桌面浏览器打开根目录的 **`index.html`**，即可看到公开诗画示例。点击「复制正文（含图片）」，在自己的公众号空白正文中正常粘贴，等待图片加载后检查。

本示例网页不请求网络、没有统计代码、不上传正文。把自己的文章交给第三方 AI 时，则按该 AI 服务的数据规则处理。

## 用自己的内容

将项目中的整个 `skills/wechat-article-kit` 文件夹、自己的文章和配图交给能读写文件的 AI。复制这段要求：

```text
请阅读 wechat-article-kit 文件夹中的 SKILL.md。
使用我这次提供的文章和图片制作公众号正文排版网页，
不要把示例诗文、示例图片或其他项目资料带进我的文章。

先沿用示例的简洁样式，图片顺序按文件名；
不确定的两图并排关系先告诉我。
保留图文复制按钮和失败提示，不需要接入公众号账号。

请输出可下载的 HTML、article.json、layout.json 和图片文件夹。
给我打开方法，并说明哪些效果还需要到公众号实际粘贴验证。
```

随后这样迭代：

```text
正文改为15px，行高1.9，段落间距22px。
第2、3张图并排，其余单张显示。
只改排版，不改文章文字，保留复制功能。
把满意的规则保存为layout.json，下一篇继续用。
```

无需先安装 Skill 才能使用：AI 能读取它及附带文件即可。只支持文字聊天、不能处理文件的 AI，无法直接替你生成下载包。支持 Skill 的工具可按它自己的安装方式安装整个文件夹，不要只复制 SKILL.md。

详细步骤见 [使用教程](docs/使用教程.md)。

## 自己运行（可选）

需要 Python 3.9 或更新版本，无额外依赖。在项目根目录执行：

```sh
python3 skills/wechat-article-kit/scripts/build_article.py examples/article.json --layout examples/layout.json --output my-article.html
```

默认不覆盖已有文件。需要覆盖你自己的生成结果时，加 `--overwrite`。

图片是相对于文章 JSON 的路径；必须放在该目录或子目录内。运行时内嵌到 HTML，交付生成的 HTML 即可预览，不依赖原图路径。

## 能做到与需要检查的地方

- 生成本地 HTML、内嵌图片、保留可复制文字、保存排版配置。
- 支持零图、单图、多组图、双图并排或上下排列，不固定为六张图。
- **无法保证公众号原样保留排版或接收所有图片。** 本项目早期实录中，网页并排的双图粘贴后变为上下排列。
- 「已写入剪贴板」仅指浏览器复制成功，不等于公众号接收成功。
- 10 MB 是本工具主动设置的正文保护阈值，不是微信官方限制。
- 标题、摘要和封面在公众号单独填写或上传。本工具不登录、不保存公众号草稿、不发布。
