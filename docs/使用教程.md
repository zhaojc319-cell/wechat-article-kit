# 从模板到自己的排版

## 1. 准备本期材料

建议把文章和图片放在单独文件夹中，图片命名为 `01.jpg`、`02.jpg` 等。明确文章段落、图片顺序、哪些图片需要并排。有参考图可以一并提供，说明想借鉴的是字号、留白还是图片布局。

只给 AI 这次需要的材料。使用本地网页不会上传文件，但向在线 AI 发送文件是另一件事。

## 2. 把工具包交给 AI

提供整个 `skills/wechat-article-kit` 文件夹。AI 需要能读取附件、运行 Python 或写入 HTML。不会安装 Skill 也没关系，直接要求它先读 SKILL.md。

如果 AI 不能运行脚本，可以让它整理 `article.json`、`layout.json` 和图片目录，再由你或有文件执行能力的工具运行。仅仅把 SKILL.md 粘贴到聊天里，不会自动给 AI 增加文件生成能力。

## 3. 先生成，再调整

先让 AI 输出一版网页。在浏览器中查看文字和图片有没有漏、顺序是否正确，再提出明确修改，例如：

```text
保留全部原文。正文16px，标题22px，左右留白24px。
将第1、2张图放在同一行，第3张独占一行。
段落间距改成22px。重新生成网页，并保存这次配置。
```

配置项未覆盖的特殊样式，可以让 AI 修改模板副本；不要把每个人的私人偏好写进公开 Skill。

## 4. 到公众号验证

打开网页，等提示「正文已准备好」，点击复制。在公众号的空白正文里用 ⌘V 或 Ctrl+V 正常粘贴。

检查：图是否完整、并排是否保留、字号间距是否合适、文字是否能编辑、手机预览是否正常。

如果失败，把截图和具体结果反馈给 AI，例如：

```text
网页两张图并排，粘到公众号后变成上下排列。
文字可以编辑，图片都在。请只调整双图布局，
不要改文字，也不要直接把两张图拼成一张。
```

AI 无法代看后台时，不应把本地预览当成公众号测试结果。文章标题、摘要、封面仍在后台单独处理。

## 5. 保存，下次复用

保留生成的 HTML、文章输入、图片和 `layout.json`。下一篇让 AI 替换文章与图片，沿用配置即可。复制按钮只是复制当前正文，不负责记忆你的偏好；偏好保存在配置文件中。

## 浏览器不让复制时

先用桌面浏览器直接打开 HTML，不要在聊天附件的内嵌预览里点按钮。现代剪贴板接口通常需要安全环境和用户点击；本地文件的权限行为因浏览器而异。

如果本地文件复制失败，在项目根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

用浏览器打开 `http://localhost:8000/`。只启动当前项目目录的本地服务，结束后按 Ctrl+C。也可以访问发布者提供的 HTTPS 示例页。没有任何一种入口能保证公众号接收所有图片。

参考：[MDN Clipboard.write](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/write)。
