# 发布到独立仓库

这是可审阅的本地发布包，尚未代表已建立线上仓库。

1. 确认对外项目名、账号和许可证署名。当前 MIT 文件采用项目贡献者署名 `wechat-article-kit contributors`，可替换为认可的公开署名；不要误填私人信息。
2. 只将这个独立项目目录推送到新的仓库。不要把视频项目总目录、录屏、私人 Skill 或其他项目历史一起上传。
3. 在自己的公众号空白正文检查示例粘贴与手机预览，记录实际结果。不把早期测试当成本版完整验收。
4. 创建仓库并放入本目录的文件。保留 LICENSE、NOTICE 和示例来源说明。
5. 如需在线演示，按 GitHub Pages 设置从发布分支根目录提供静态页面，入口是 `index.html`。该页面没有用户上传入口或在线 AI。
6. 发布下载包和简短使用说明，链接到 README。没有现成在线服务时，不要填写虚构的体验链接。
