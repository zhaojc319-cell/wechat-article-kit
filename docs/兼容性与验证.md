# 兼容性与验证边界

## 已知实际结果

早期公开素材演示中，网页双图并排在公众号粘贴后变为上下排列。这是实际兼容性结果，不应宣传为“所有格式原样保留”。

当前开源版重新整理了输入、配置、图片检查和错误提示。早期演示不能替代对本版在公众号的完整验证。发布前请自行检查后台和手机预览。

## 复制含义

按钮写入 HTML 和纯文本两种剪贴板内容；图片在 HTML 内作为 data URL。目标编辑器可能过滤布局样式或拒绝图片数据。因此：

- 网页加载成功 ≠ 浏览器复制成功。
- 浏览器复制成功 ≠ 公众号图片接收成功。
- 公众号桌面显示正常 ≠ 手机预览正常。

## 体积与图片

正文保护阈值为10,000,000字节。图片转成 Base64 后通常比原始文件大；脚本与网页都检查正文体积。这个数值是项目设置，不是微信官方公布的限制。

支持 JPEG、PNG 和 WebP。脚本检查文件标记，浏览器继续检查图片是否能实际解码。大图可先压缩；脚本不会静默降低图片质量。

并排默认用内联 flex 布局；它在目标编辑器中可能失效。可改用上下排列，或由用户与 AI 继续验证其他布局。不会默认把两张图片拼成不可分别编辑的一张。

## 反馈建议

反馈时提供浏览器及版本、操作系统、图片数与正文体积、复制状态、实际粘贴表现。截图先隐藏账号、文章私密内容和其他会话。不要提交公众号密码、Cookie 或真实业务文章。
